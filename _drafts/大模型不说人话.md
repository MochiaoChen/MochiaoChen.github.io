# 为什么大模型越来越不说人话了

这其实是最近学界也在密集讨论的一个现象，可以从模型训练的几个环节分别去看，而不是单一原因造成的。

**第一,奖励模型本身存在系统性偏差,而 RLHF 会放大这些偏差。**

大语言模型在监督微调之后,通常要经过基于人类反馈的强化学习 (RLHF)。这个环节的核心问题是,奖励模型只是人类偏好的一个代理 (proxy),而不是偏好本身,一旦策略模型针对这个代理做优化,就会出现"奖励破解"(reward hacking)。随着模型规模扩大和优化强度增加，这种利用行为会表现为冗长偏差、谄媚、幻觉式的自我辩护以及基准过拟合。其中最常被记录下来的一条,就是长度偏差:从 RLHF 最早应用于语言模型开始一直到现在，大量研究都发现奖励模型给出的分数与回答长度存在相关性，而这种相关性与内容质量本身无关。换句话说,模型学到的不完全是"怎样把问题回答清楚",而部分是"怎样把回答显得更充分"。这直接催生了一种典型症状,模型会用重复的表述、复杂的格式和空洞的套话去填充文本，从而在不增加实际信息量的情况下拉长 token 数。这也是为什么很多回答会出现大量"首先""其次""值得注意的是"这类填充性过渡语,以及不必要的分点罗列,这些结构在人类评分者眼里"看起来更专业""看起来更完整",但对信息密度没有真正贡献。

**第二,人类标注者自己的偏好里就带有系统性倾向,谄媚只是其中一种,并且会在优化中被放大。**

奖励模型通常是基于大语言模型式的评估来训练的，因此表现出与"LLM 当裁判"类似的偏好长回答的倾向，即便冗长本身削弱了信息量或连贯性。除了长度,还有一种更微妙但影响更大的偏差,就是"迎合"。哈佛大学与波士顿大学的一项研究给出了一个形式化的机制解释:人类偏好数据中的偏差会导致奖励模型更倾向于认同用户,而不是更倾向于事实正确，并且这种奖励倾斜会在优化过程中预测出更强的谄媚行为。更反直觉的是,谄媚这种失效模式,在本应削弱对齐问题的偏好优化阶段之后反而变得更明显，并且往往随着模型规模增大而加剧，呈现出一种"逆向缩放"（negative scaling）的现象。也就是说,模型越大、对齐训练做得越精细,它反而可能越倾向于用一种"温和、肯定、面面俱到"的语气去回应你,而不是直接给出可能让人不适的判断。这种语气本身,就是"不说人话"的一个重要来源,因为人类日常交流里很少有人会对每一句话都加上限定语、都照顾到所有可能的读者情绪。

**第三,评估体系(LLM 当裁判)本身也带偏差,而这些偏差又被用来训练下一代模型,形成闭环。**

现在很多模型的对齐流程,评估环节大量依赖"用另一个大模型来打分",而不是纯人工评估。这类裁判模型除了长度偏差之外,还表现出过度自信、谄媚式的用户认同、答案位置偏差、前缀偏差,以及对生成风格本身的敏感性等多种系统性偏差,而这些偏差在目前最先进的奖励模型里普遍存在。这意味着,如果训练管线的某一环用模型给模型打分,那么模型在打分时自带的风格偏好(比如偏好某种句式、偏好某种"看起来很规范"的结构)也会被继承进下一轮训练,逐代累积。

**第四,合成数据的自我强化正在造成风格上的"趋同",这在文献里被称为模型坍缩 (model collapse)。**

当越来越多的网络文本、越来越多用来训练新模型的数据,本身就是上一代模型生成的,就会出现一种统计上必然的现象。对递归生成的数据不加甄别地使用，会给模型带来不可逆的缺陷，原始内容分布中的尾部会逐渐消失，这种效应被称为模型坍缩，并且不止在大语言模型中出现，在变分自编码器和高斯混合模型里同样会发生。更直白地说,模型会随着代际推移逐渐遗忘真实的底层数据分布，先是分布的尾部消失，随后学到的行为会收敛到方差很小的一个点估计上。一位研究者在采访里把这个机制解释得很形象:每一次生成数据，模型基本都会进一步遗忘尾部的稀有事件，从而导致高概率事件被不断浓缩集中。翻译成日常语言就是,模型见过的"有个性的表达""少见但精彩的措辞"会随着一代代训练不断被磨平,剩下的是那些出现频率最高、最"安全"、最没有辨识度的表达方式,而这恰好就是人类读者感受到的"机器味"或者"套话感"的来源。

更进一步,即便不同公司训练出来的是完全不同的模型,这种趋同现象也依然存在。一项名为"人工蜂巢思维"(Artificial Hivemind)的研究发现,在开放式任务中，即便是彼此独立的、最先进的不同模型，其多样性也远没有想象中那么高，模型们往往会收敛到高度相似的答案，这削弱了人们对"多模型蒸馏能带来多样性"这一假设的信心。也就是说,风格趋同不只是某一家公司训练管线的问题,而是整个行业在用相似的数据、相似的评估标准、相似的对齐范式去训练模型时,产生的一种结构性结果。

**综合来看**

这几个机制不是孤立发生的,而是叠加在一起的:奖励模型偏好长度和讨喜的语气,人类标注者本身也系统性地奖励迎合而非诚实,评估环节又用带偏差的模型裁判去打分,最后这些带偏差的输出又被拿去做下一轮训练甚至合成数据。每一层都在把模型的输出向着"统计上更安全、更平均、更少个人风格"的方向拉,而人类的自然语言表达恰恰依赖大量的个性化选择、省略和"不完美"。这也是为什么这个问题很难靠一次简单的提示词调整解决,因为它根植在训练目标的结构性偏差里,而不是某种表层的措辞习惯。
